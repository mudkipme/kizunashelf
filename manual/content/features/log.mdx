Choose **Log** on an entity to record a viewing session, a game milestone, or a thought you want to remember. The date defaults to today; change it to record something you did earlier. Add a note, check the preview and destination, then choose **Log** to save it.

For example, logging a rewatch might add:

```markdown
- [[Steins;Gate 0 (Anime)]] — finished my rewatch #Anime
```

That link connects the day to the entity. You can find it later in the entity's history and the [activity feed](./calendar.mdx).

## Status changes

A **Started** or **Completed** log can also record the corresponding date and update the entity's status when its type supports it. Starting something resumes a paused entity, but does not move a completed entity back to in progress. Dropped entities are left as they are.

Logging and [episode checklists](./episodes.mdx) are separate: a log does not tick episodes, and ticking an episode does not add a daily-note line.

## Configuring daily notes

In the schema settings, choose your daily-notes folder and date format. You can also choose a template for new notes, a heading for log lines, and the wording of each type's log.

If you already use daily notes in Obsidian, use the same folder and date format in both apps. Mentions you write by hand count as activity too.

For the available settings and template tokens, see the [daily-note reference](../reference/home-tags-daily-notes.md#daily-notes). On iOS, logging is also available through [Siri and Shortcuts](./ios.mdx#siri-shortcuts--the-action-button).
