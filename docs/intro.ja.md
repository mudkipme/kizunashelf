# KizunaShelf

> 好きなものすべてを並べる本棚。そして、そのすべてはずっとあなたのもの。

KizunaShelfは、観たもの、遊んだもの、読んだもの、聴いたもの、そして心に残しておきたいものを集める、自分だけのライブラリです。メディアトラッカーとして親しみやすい姿を持ちながら、本棚の形を決めるのはアプリではありません。どんな種類のものを置くのか、どんな情報を持たせるのか、何と何を結びつけるのか。そのすべてを自分で選べます。

その土台にあるのは、自分のフォルダに置かれた、ごく普通のMarkdownファイルです。KizunaShelfは、それらを眺め、整理し、振り返るための生きた本棚に変えてくれます。それでも、ファイルがKizunaShelfにしか読めないデータへ変わることはありません。

KizunaShelfは、ドラマ、映画、本、ゲーム、アニメ、音楽といった馴染みのあるコレクションから始まります。しかし、「もの」がどんな形であるべきかは決めません。タイトル、カバー、ステータス、日付、評価、進捗、関係性は、すべてスキーマで定義できます。キャラクターやクリエイター、ライブイベント、あるいは自分だけが整理したいと思う何かまで、KizunaShelfはそれを記述するための「文法」を提供します。

この本棚は平面ではありません。ゲームはシリーズに属し、アニメは小説を原作に持ち、キャラクターは声優へとつながっていく。Markdownに書いた普通のWikiLinkが、ライブラリを横切る関係の地図として読み解かれます。ひとつひとつの項目だけでなく、そのあいだにある由来やつながりも、本棚の一部になります。

そして時間が、その地図に歴史を与えます。発売日や放送予定、これからの計画、すでに終えた記録は、同じカレンダーに並びます。日々のノートで何かに触れれば、その一日と大切なものが結びつきます。エピソードにチェックを入れれば、日付のついたアクティビティとして残ります。ひとこと記録するときは、自分で決めた書式に沿って、その日のMarkdownノートへ一行を書き戻すこともできます。アクティビティフィードは、観たもの、遊んだもの、読んだもの、そして楽しみに待っていた時間を、あとから辿れる記録へとまとめます。

それが *kizuna*――自分と、手元に残してきたものとのあいだにある「絆」です。

そして、ファイルはいつでも自分のものです。Markdownが本当のデータ源であり、Obsidian、SilverBullet、Zed、VS Code、どんなテキストエディタでも、あるいは特定のアプリがなくても読み続けられます。いつかKizunaShelfを使わなくなったとしても、ノートも、フィールドも、リンクも、記憶も、そこに紡がれた絆も消えません。

KizunaShelfは、大切なものを並べる本棚であり、それらがどのように人生へ集まってきたのかを残す記録簿です。
