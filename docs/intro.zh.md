# KizunaShelf

> 一座安放你所爱之物的书架——而它，始终属于你。

KizunaShelf 是一个属于你的个人收藏库，用来记录你看过、玩过、读过、听过，以及所有真正在意的事物。它有着媒体追踪器所熟悉的模样，却不替你规定收藏应该长成什么样：要收录哪些类型、使用哪些字段、又该如何彼此相连，都由你决定。

在这一切之下，每个条目仍然是你所拥有的文件夹里一份普通的 Markdown 文件。KizunaShelf 让这些文件成为一座可以浏览、整理和回望的书架，却不会把它们变成只有某个应用才能读懂的数据。

KizunaShelf 从剧集、电影、书籍、游戏、动画和音乐这些熟悉的收藏开始，却不预设一个「东西」应该是什么。标题、封面、状态、日期、评分、进度和关系，都由你的 schema 来定义。如果你的世界还需要角色、歌手、现场演出，或某种只有你自己才会想到要整理的事物，KizunaShelf 也给你一套描述它们的语言。

这座书架不是平面的。一个游戏可以属于某个系列，一部动画可以改编自某本小说，一个角色可以连接到为其配音的声优。写在 Markdown 里的普通 WikiLink，会被读成贯穿收藏库的脉络；每个条目不再只是孤立地存在，也带着它与其他事物之间的来路和去向。

而时间，让这些关系有了历史。发售日与播出时间、未来的计划和已经完成的记录，都可以出现在日历上。在日记里提到某个条目，那一天便和它连在一起；勾选一集，会留下一条带日期的活动记录；随手写下一笔时，KizunaShelf 也可以按照你定义的格式，把它写回当天的 Markdown 日记。活动流再把这些片段聚拢起来，让你重新看见自己曾在何时看过、玩过、读过，又曾为什么而期待。

这就是 *kizuna*：你与珍藏之物之间的羁绊。

而这些文件始终属于你。Markdown 才是真正的数据源，可以继续由 Obsidian、SilverBullet、Zed、VS Code、任何文本编辑器，甚至不依靠任何应用来阅读。即使有一天 KizunaShelf 离开了，你的笔记、字段、链接、记忆与羁绊，也不会随它消失。

KizunaShelf 是一座收藏重要之物的书架，也是一本记下它们如何来到你生命里的记录簿。
