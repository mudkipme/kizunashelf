# Security policy

Security fixes target the current `main` branch and the latest published image. Use a version tag or image digest when you need a reproducible deployment.

Report suspected vulnerabilities using [GitHub's private vulnerability reporting](https://github.com/mudkipme/kizunashelf/security/advisories/new). Include the affected version or image digest, reproduction steps with synthetic data, and the expected impact. Avoid posting credentials or a real vault. Please keep exploit details out of public issues while a report is being investigated.

For deployment settings, HTTPS, authentication, and read-only mode, see the [self-hosting guide](manual/content/start/self-hosting.md).
